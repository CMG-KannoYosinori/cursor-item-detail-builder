# 案件ごとの作業フロー

## `00000` → プロジェクト ID のプレースホルダ規約

`00000`（およびそこから派生するクラスプレフィックス `p00000`）は、案件のプロジェクト ID（数字、例: `15403`）を表すリテラルなプレースホルダです。実案件の作業を始める際は次の手順を踏みます。

1. `00000html` フォルダを丸ごと複製し、`{id}html` フォルダを作る（例: `00000html/` → `15403html/`）。**複製元の `00000html/` は変更・移動せず、常にテンプレートとして残す。**
2. 複製した `{id}html` フォルダ内に限定して、`00000` → プロジェクト ID の一括置換をすべてのファイル種別（HTML/CSS/`.vscode/settings.json` など）に対して行う。ただし `README.md` / `はじめてガイド.md` は汎用的な説明文書であり、置換例として `00000` を意図的に使っているため対象外とする。
3. `dist/00000.html` → `dist/{id}.html` にリネームする（一括置換はリネームまではカバーしない）。
4. 商品 URL（例: `000000000177`）など `00000` を偶然含む無関係な数字列に注意する。単純な文字列置換だと `000000000177` のような連続した数字列まで書き換えてしまうため、`00000` の前後が数字でない場合のみ置換する（例: 正規表現 `(?<!\d)00000(?!\d)`）。置換後は目視でも確認し、意図せず変わっていないかチェックする。

特定の案件ではなく「テンプレート自体（このリポジトリの現状、`00000html/`）」に対する作業を依頼された場合は、指示がない限り `00000` はそのままにしておく。

`/coding`（@coding-workflow.md）からこのフローに入った場合、上記 1〜4 はユーザーに手順を案内するのではなく、**エージェントが自動で実行する**。

## ローカル / CDN アセットの切り替え

`dist/*.html` は開発中、CSS とアコーディオン用スクリプトをローカル参照しており、すぐ隣に本番用 CDN の URL がコメントアウトされた状態で併記されています。

```html
<link href="./styles/style.css" rel="stylesheet" type="text/css" />
<!-- <link href="https://image.moratame.net/images/detail/{id}/styles/style.css" rel="stylesheet" type="text/css" /> -->
```

```html
<script src="./scripts/accordion.2.js"></script>
<!-- <script src="https://image.moratame.net/images/detail/{id}/scripts/accordion.2.js"></script> -->
```

公開前には、対応するアセットを画像サーバへアップロードしたうえで、両方のペアを入れ替えます（ローカル行をコメントアウトし、CDN 行を有効化する）。これらのファイルを編集する際は、どちらかの行を削除せず、このペアのコメント構造を保つこと。

## 2 ファイル構成（編集用／参照用、任意だがよく使われる）

`dist/00000.html` を複製して `dist/reference.html` を作るチームも多くあります（プレースホルダ置換の影響を受けないよう、意図的にプレフィックスなしの名前にしている）。番号付きファイルが実際に編集・納品する対象で、`reference.html` は部品のマークアップをコピーするための参照用として手を加えずに残します。Live Server は `reference.html` ではなく番号付きファイルの方を開くようにする。
