## 全体の流れ（チェックリスト）

### A. ファイルを用意する

**初めてのとき（または公式テンプレを取り直すとき）**

1. [ ] GitHub で **Code → Download ZIP**
2. [ ] ZIP を解凍する
3. [ ] **`00000html` フォルダだけ残す**（ほかは全部削除してよい）
4. [ ] `00000html` を作業用の場所へ移す
5. [ ] VS Code / Cursor で **`00000html` フォルダを開く**（中のファイル単体ではなく、フォルダごと）

残す中身:

```

├── README.md           ← くわしい説明
├── dist/                ← ここを編集・納品する

**2回目以降の案件**は、毎回 GitHub から取り直さず、自分用に整えた `00000html` をコピーして使うと楽です（下の「使い方のコツ」参照）。
### B. 番号を案件用に変える（最初に必ず）

1. [ ] サイドバーで `00000html` フォルダをクリックして選ぶ
2. [ ] 検索置換を開く（Mac: `Cmd + Shift + F` / Windows: `Ctrl + Shift + F`）
3. [ ] 次を **すべて置換** する

```

4. [ ] フォルダ名を手動で変える: `00000html` → `15403html`
5. [ ] HTML ファイル名を手動で変える: `dist/00000.html` → `dist/15403.html`

> 置換のあと、変えたくない番号（商品 URL など）が変わっていないか、ざっと確認する。

### C. プレビューできるようにする

1. [ ] `dist/15403.html` を開く
2. [ ] 右クリック → **Open with Live Server**（または同様のメニュー）
3. [ ] ブラウザでページが表示されればOK

### D. ページを作る（日常作業）

触る場所はこの2つだけです。

| やりたいこと | 開く場所 |
| ------------ | -------- |
| 文章・画像・ボタンなどの中身 | `dist/〇〇〇〇〇.html` |
| 色・余白・レイアウトなどの見た目 | `dist/styles/style.css` |

**やってよいこと**

- HTML に文章や画像を足す・直す
- 案件だけの見た目は `dist/styles/style.css` の「Pages — project」という見出しコメントの下に書く
- 既存の部品（ボタンなど）をまねして使う

**やらなくてよい／やってはいけないこと**

- `npm` やターミナルは使わない
- わからないファイルは触らない

`dist/styles/style.css` はこのファイル自体が編集対象です。保存すると Live Server が自動でブラウザをリロードします（裏で何かをビルドし直す、という工程はありません）。

### E. 公開前

1. [ ] HTML 内の CSS を、ローカル用から本番用（CDN）に切り替える
   （`./styles/style.css` をコメントアウトし、本番 URL の行を有効にする）
2. [ ] アコーディオン（開閉メニュー）を使っている場合
   - `dist/scripts/accordion.2.js` をサーバへアップロード
   - HTML 末尾の script もローカル → 本番 URL に切り替える
3. [ ] 画像を所定の場所へ置く／アップロードする
4. [ ] Live Server を止めてもよい

## 使い方のコツ（おすすめ）

### 1. 自分用テンプレをコピーして使う

毎回 GitHub から ZIP をダウンロードする必要はありません。

1. 一度 GitHub から `00000html` を用意する
2. よく使う部品・文章・見た目など、**自分用にカスタマイズした状態**を残しておく
3. 新しい案件が始まったら、そのフォルダを **コピー** してから番号置換する

こうすると、案件ごとに同じカスタマイズをやり直さなくて済みます。
公式テンプレが大きく変わったときだけ、GitHub から取り直せば十分です。

### 2. HTML を「参照用」と「編集用」に分ける

`dist/00000.html` を **複製** し、参照用のファイル名は **`reference.html`** にします（プロジェクト ID を付けない）。
一括置換してもファイル名が変わらないので、どの案件でも「参照用はいつも `reference.html`」とわかります。

例:

```
dist/
├── 00000.html      ← 編集用（置換後は 15403.html など。ここに書き足していく）
└── reference.html  ← 参照用（どの案件でもこの名前。基本いじらない）
```

参照用から、ボタン・商品カード・アコーディオンなどのまとまりをコピーして、編集用へ貼り付けます。
元の見本を消さずに済むので、部品の使い回しが楽になります。

> Live Server で開くのは **編集用** の HTML にしてください。
